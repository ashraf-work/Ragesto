Mere project me abhi Razorpay payment functionality lagi hui hai, lekin mujhe Razorpay completely remove karke Stripe payment gateway integrate karna hai.

Project structure:
- `Client` folder = Frontend code
- `Server` folder = Backend code

Tum dono folders ka code carefully check karo aur jahan jahan Razorpay use ho raha hai, usko remove/replace karke Stripe ki full working test payment functionality implement karo.

Requirements:
1. Razorpay related packages, imports, API routes, controllers, services, frontend logic, scripts, env variables sab remove/replace karo.
2. Stripe integration same flow ke sath honi chahiye jo Razorpay me thi.
3. Backend me Stripe payment intent / checkout session ka proper API banao.
4. Frontend me payment button/checkout flow Stripe ke sath connect karo.
5. Backend aur frontend dono me required `.env.example` variables add/update karo.
6. Real Stripe test keys ke liye env variable names use karo, hardcode mat karna.
7. Payment success/failure handling properly implement karo.
8. Order/booking/payment status update logic existing Razorpay wali logic ke according Stripe ke sath adjust karo.
9. Error handling clean aur production-ready honi chahiye.
10. Code run karke check karo ke frontend aur backend dono error-free hain.

Stripe env variables example:
Server:
STRIPE_SECRET_KEY=
STRIPE_WEBHOOK_SECRET=
CLIENT_URL=

Client:

VITE_API_BASE_URL=
